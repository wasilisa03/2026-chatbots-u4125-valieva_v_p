##Отчет по лабораторной работе №2: «Подключение бота к данным»##

##Описание интеграции##

В качестве источника данных для второй лабораторной работы я выбрала CSV‑файл с информацией о сотрудниках. 

##Промпт для LLM##

Исходный промпт я составила так: «Добавь в моего Telegram‑бота для сбора обратной связи работу с CSV файлом сотрудников. Нужны команды: /employees — показать всех сотрудников, /search [имя] — поиск по имени, /department [отдел] — сотрудники из отдела. Структура CSV: name, department, role, email. Используй pandas. Сохрани весь существующий функционал». После первой итерации бот стал показывать сотрудников, но поиск работал только по точному совпадению. Пришлось уточнить: «Сделай поиск по частичному совпадению имени, без учёта регистра». Также я добавила кнопки в главное меню для удобства. Финальный промпт выглядел так: «Добавь в бота для отзывов работу с CSV. Реализуй команды /employees (показать всех), /search (частичное совпадение по имени, регистронезависимо), /department (точное совпадение отдела без учёта регистра). Используй pandas. Добавь кнопки в меню /start. Не ломай существующий функционал отзывов».

##Реализация##

Интеграция работает следующим образом: при запуске бот загружает файл employees.csv через pandas, преобразует его в список словарей и кэширует, чтобы не читать диск при каждом запросе. Команда /employees просто выводит всех сотрудников в виде форматированного сообщения. Команда /search принимает аргумент (имя), переводит его в нижний регистр и ищет частичное совпадение в колонке name, после чего возвращает найденных сотрудников. Команда /department работает похоже, но ищет точное совпадение по отделу. Ключевые фрагменты кода:

Загрузка CSV: df = pd.read_csv(CSV_PATH); rows = df.to_dict('records')

Поиск по имени: if name_lower in e['name'].lower()

Форматирование вывода: f"👤 {e['name']}\n Отдел: {e['department']}\n Должность: {e['role']}\n Email: {e['email']}"

Используемые библиотеки: pandas (для чтения CSV), telegram.ext (CommandHandler для обработки команд), а также стандартные модули os, csv, logging. Pandas пришлось добавить в requirements.txt, что увеличило размер деплоя, но упростило работу с таблицами.

##Тестирование##

Я проверила все команды в Telegram. При вводе /employees бот вывел таблицу из пяти сотрудников с их отделами и должностями. При запросе /search Иван бот нашёл Ивана Иванова, даже если имя написано строчными буквами. При /search ан бот показал всех, у кого в имени есть «ан» (Иван, Семён и т.д.). Команда /department IT вывела только сотрудников из IT-отдела. Также я убедилась, что старый функционал (сбор отзывов) не сломался: после тестирования CSV-команд я оставила отзыв, и он успешно сохранился в базу данных. Скриншоты работы прилагаю, видео‑демо записано на 2 минуты.
