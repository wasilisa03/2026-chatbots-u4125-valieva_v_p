# Telegram-бот для сбора обратной связи

## Описание

Бот позволяет сотрудникам оставлять отзывы и рекомендации. Все данные сохраняются в SQLite.
Доступна статистика по количеству отзывов.

## Требования

- Python 3.9+
- Библиотеки из requirements.txt

## Установка и запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` на основе `.env.example` и укажите токен бота:
   ```bash
   cp .env.example .env
   ```
3. Запустите бота:
   ```bash
   python bot.py
   ```
4. Используйте команды `/start`, `/stats` и кнопку "Оставить отзыв" в меню.
